Vercel 部署失败，原因是 TypeScript 编译错误。主要包括未使用的变量 (`TS6133`) 和 Framer Motion 的类型不匹配 (`TS2322`)。

**问题列表与分析：**

1.  **`src/App.tsx`**: `error` is declared but its value is never read.
    *   Line 23: `static getDerivedStateFromError(error: any)` -> `error` 未使用。
2.  **`src/components/AdminRoute.tsx`**: `React` is declared but its value is never read.
    *   Line 1: `import React, ...` -> React 17+ 可能不需要显式引入 React（除非用到）。
3.  **`src/context/AuthContext.tsx`**: `api` is declared but its value is never read.
    *   Line 2: `import api from '../api/axios';` -> 未使用。
4.  **`src/pages/Admin/AdminLayout.tsx`**: `useState`, `useEffect`, `user` 未使用。
    *   Lines 1, 7: 引入了但没用。
5.  **`src/pages/Admin/PostManagement.tsx`**: `loading` 未使用。
    *   Line 29: 定义了 `loading` 状态但 UI 没用到。
6.  **`src/pages/Home.tsx`**: `itemVariants` 类型错误。
    *   Line 321: `variants={itemVariants}` -> `TS2322`.
    *   `itemVariants` 定义是 `{ hidden: { y: number; opacity: number; }, visible: { ... } }`。
    *   Framer Motion 的 `Variants` 类型期望更具体的结构。通常是因为类型推断不完全匹配接口。简单的修复是显式声明类型 `Variants` 或使用 `any` 绕过，或者修正对象结构。

**解决方案：**

1.  **修复 TS6133 (Unused variables)**:
    *   删除未使用的导入和变量声明。
    *   或者对于必须存在的参数（如生命周期方法），使用下划线前缀 `_error` 或简单地忽略。
    *   `App.tsx`: `getDerivedStateFromError(_: any)`。
    *   `AdminRoute.tsx`: 删除 `React`。
    *   `AuthContext.tsx`: 删除 `api`。
    *   `AdminLayout.tsx`: 删除 `useState`, `useEffect`, `user`。
    *   `PostManagement.tsx`: 使用 `loading`（显示加载状态）或删除它。

2.  **修复 TS2322 (Home.tsx Variants)**:
    *   引入 `Variants` 类型并显式标注。
    *   `import { motion, Variants } from 'framer-motion';`
    *   `const itemVariants: Variants = { ... };`
