用户希望优化标签输入的体验：
1.  **不需要回车确认**：目前是回车或点击推荐项确认。
2.  **鼠标移开自动确认**：即 `onBlur` 事件触发时，如果输入框里有内容，自动将其作为标签添加。

**现状分析**：
目前 `Write.tsx` 中的 `handleTagInputBlur` 逻辑是：
```javascript
  const handleTagInputBlur = () => {
    setIsInputFocused(false);
    // 延迟关闭下拉，以便能够点击下拉项
    setTimeout(() => {
      setShowTagDropdown(false);
    }, 200);
  };
```
以及 `input` 的 `onBlur={handleTagInputBlur}`。

**修改方案**：
修改 `handleTagInputBlur`，在失焦时检查 `tagInput` 是否有内容。如果有，尝试调用 `handleAddTag`。

**注意点**：
1.  `handleAddTag` 目前会清空 `tagInput`。
2.  `setTimeout` 仍然需要，因为如果是点击了下拉列表项导致的失焦，我们希望优先触发下拉列表的点击事件（添加标签），而不是触发 `onBlur` 的添加。
3.  如果点击下拉项，`handleAddTag` 会被调用一次。如果 `onBlur` 也调用 `handleAddTag`，可能会导致重复添加（虽然 `handleAddTag` 内部有去重逻辑，但会多次触发）。
4.  更重要的是，如果用户点击的是“取消”或者页面的其他地方，这时候自动添加是合理的。但如果用户点击的是下拉列表里的**另一个标签**，这时候输入框里的内容（可能是匹配的一半）是否应该被添加？
    *   例如输入 "Re"，下拉显示 "React"。用户点击 "React"。
    *   `onBlur` 触发 -> 尝试添加 "Re"。
    *   `onClick` 触发 -> 添加 "React"。
    *   结果：添加了 "Re" 和 "React"。这可能不是用户想要的。

**优化逻辑**：
通常的做法是：
*   如果用户点击了下拉列表项，`onBlur` 的逻辑应该被取消或忽略。
*   或者，`handleAddTag` 在添加成功后会清空 `tagInput`。
*   如果 `onBlur` 先执行，它会把 "Re" 加进去并清空 input。然后 `onClick` 执行时，input 已经空了，但这不影响 `onClick` 传参。
*   **关键问题**：如何区分“点击下拉项”导致的失焦和“点击空白处”导致的失焦？
    *   利用 `setTimeout`。
    *   在 `onClick` 里，我们不需要做特殊处理，因为它直接传具体的 tag。
    *   在 `onBlur` 里，我们延迟执行“自动添加”。
    *   但是，如果用户点击的是下拉项，`onBlur` 会先触发。
    *   如果 `onBlur` 把当前输入 "Re" 加进去了，用户体验可能不好（用户本意是选 "React"）。

**更智能的策略**：
如果下拉列表**有完全匹配项**，或者用户正在从下拉列表中选择，通常不应该自动添加输入框里的“残缺”内容。
但用户的需求是“鼠标移开自动实现确认”，这通常指“输入完毕点击别处”。

**简单实现方案**：
在 `handleTagInputBlur` 中，延迟执行 `handleAddTag(tagInput)`。
为了避免与下拉选择冲突，可以在下拉列表的 `onMouseDown` (它早于 `onBlur`) 中阻止默认行为 `e.preventDefault()`，这样点击下拉项不会导致 input 失焦！
或者，保持失焦，但在 `onBlur` 中判断。

**最稳妥的方案（结合用户指令）**：
用户明确说“鼠标移开自动确认”。这意味着把当前输入框里的东西加进去。
如果用户点击下拉列表项，那应该是优先采纳下拉项。
由于 `click` 事件晚于 `blur`，如果 `blur` 把输入框清空了，视觉上会闪烁。

**改进方案**：
1.  修改 `handleTagInputBlur`，在延迟后（比如 200ms），如果 `tagInput` 还有值，就添加它。
2.  修改下拉列表项的 `onClick`：它会立即添加选中的标签，并清空 `tagInput`。
3.  这样，当用户点击下拉项时：
    *   `blur` 触发 -> 200ms 计时开始。
    *   `click` 触发 -> 添加选中标签 -> 清空 `tagInput`。
    *   200ms 到期 -> 检查 `tagInput` -> 发现为空 -> 不做操作。
    *   **完美！**

**除了一个边缘情况**：如果用户输入的是一个新标签（不在推荐里），然后点击页面空白处。
*   `blur` 触发 -> 200ms 计时开始。
*   没有 `click` 事件。
*   200ms 到期 -> `tagInput` 有值 -> 执行 `handleAddTag` -> 添加成功 -> 清空 input。
*   符合用户需求。
