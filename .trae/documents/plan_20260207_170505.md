根据 `database.md` 的设计，我将创建 SQL 建表语句和初始化脚本。

**注意**：要运行初始化脚本自动创建表，您需要在 `.env.local` 中添加 PostgreSQL 连接字符串（`DATABASE_URL`），因为当前的 Supabase Anon Key（公开密钥）通常没有权限直接执行 `CREATE TABLE` 等建表操作。

### 1. 创建 SQL 架构文件
我将创建 `src/db/schema.sql` 文件，包含以下表的定义：
- **users (用户表)**:
  - `id`: UUID (主键)
  - `username`: 文本 (唯一)
  - `email`: 文本 (唯一)
  - `password`: 文本 (加密存储)
  - `avatar`: 文本 (头像 URL)
  - `created_at`: 时间戳
- **categories (分类表)**:
  - `id`: UUID (主键)
  - `name`: 文本 (唯一)
  - `description`: 文本
- **articles (文章表)**:
  - `id`: UUID (主键)
  - `title`: 文本
  - `content`: 文本 (Markdown)
  - `cover`: 文本 (封面图)
  - `category_id`: UUID (外键 -> categories.id)
  - `tags`: JSONB (标签数组)
  - `author_id`: UUID (外键 -> users.id)
  - `views`: 整数 (默认 0)
  - `created_at`, `updated_at`: 时间戳

### 2. 创建初始化脚本
我将创建 `src/scripts/init-db.js`：
- 使用 `pg` 库连接数据库。
- 读取 `src/db/schema.sql` 文件内容。
- 执行 SQL 语句以创建表。

### 3. 更新 package.json
- 添加 `db:init` 脚本命令，方便运行初始化：`node src/scripts/init-db.js`。
