1.  **初始化前端项目**
    *   在当前目录下运行 `npm create vite@latest client -- --template react-ts` 创建 React + TypeScript 项目。
    *   进入 `client` 目录。
    *   安装依赖：`npm install react-router-dom axios react-markdown`。

2.  **配置路由结构**
    *   在 `client/src` 下创建页面组件：
        *   `pages/Home.tsx` (首页 - 文章列表)
        *   `pages/PostDetail.tsx` (文章详情)
        *   `pages/Write.tsx` (写文章 - 需登录)
        *   `pages/Profile.tsx` (个人中心 - 需登录)
        *   `pages/Login.tsx` (登录)
        *   `pages/Register.tsx` (注册)
    *   修改 `client/src/App.tsx` 配置 `react-router-dom` 的路由规则。
    *   创建一个简单的 `auth` 上下文或状态管理，用于处理“需登录”的路由保护（Private Route）。

3.  **配置 Axios**
    *   创建 `client/src/api/axios.ts`，配置 baseURL（指向后端 `http://localhost:3000/api`）和拦截器（自动携带 Token）。

4.  **代理配置**
    *   配置 `client/vite.config.ts` 的 `server.proxy`，将 `/api` 请求转发到后端服务器（`http://localhost:3000`），解决跨域问题。
