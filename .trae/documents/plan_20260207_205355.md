用户希望将用户在 `Write.tsx` 页面输入的标签，在点击发布按钮（`handleSubmit`）后，同步到后端数据库内。

**背景回顾：**

1. 之前我移除了 `Write.tsx` 中所有的标签同步逻辑（即移除了 `api.post('/users/tags')` 的调用），因为用户当时要求“清除所有逻辑，实现单纯的展示”。
2. 之后我创建了 `user_tags` 数据库表。
3. 现在用户明确要求：标签输入并发布后，要同步到数据库。这通常意味着要将这次文章用到的标签保存到用户的“常用标签库”中。

**计划步骤：**

1. **修改** **`handleSubmit`**：

   * 在提交文章数据（`api.post('/posts')` 或 `api.put('/posts/:id')`）**之前**或**同时**，调用 `api.post('/users/tags')`。

   * 需要确保只同步**新标签**，或者后端接口已经处理了去重（根据之前的搜索结果，后端 `updateUserTags` 使用了 `ON CONFLICT` 和 `RETURNING`，并接收整个标签数组，看起来是覆盖更新）。

   * **后端逻辑确认**：后端 `updateUserTags` 接收 `{ tags: [] }`，并将该用户的标签列表**更新**为这个数组。

   * **问题**：如果直接发当前的 `tags`，会覆盖用户之前的所有标签吗？

     * 回顾 `userController.js`：

       ```javascript
       const query = `
         INSERT INTO user_tags (user_id, tags)
         VALUES ($1, $2)
         ON CONFLICT (user_id) 
         DO UPDATE SET tags = $2, updated_at = CURRENT_TIMESTAMP
         RETURNING tags
       `;
       ```

     * 是的，它是**覆盖更新**。这意味着如果我只发当前文章的标签，用户以前存的其他标签就会丢失。

   * **改进逻辑**：

     1. 先获取用户当前的标签列表（`GET /users/tags`）。
     2. 将当前文章的新标签合并进去，去重。
     3. 将合并后的列表发送回后端（`POST /users/tags`）。

   * 或者，更简单的做法（如果允许覆盖或只关心当前）：不，不能覆盖。必须合并。

   * 但是，之前的 `Write.tsx` 是有 `availableTags` 状态的，且在初始化时获取了。我之前把它删了。

   * **现在的** **`Write.tsx`** **没有** **`availableTags`**，只有当前文章的 `tags`。

   * 所以，为了安全同步，我需要在 `handleSubmit` 里：

     1. 调用 `api.get('/users/tags')` 获取旧标签。
     2. 合并 `oldTags` 和 `currentTags`。
     3. 调用 `api.post('/users/tags')` 保存。

2. **具体代码实现**：

   * 在 `handleSubmit` 函数中，在提交文章前添加同步逻辑。

   * 考虑到网络请求的异步性，可以使用 `Promise.all` 或者顺序执行。为了不阻塞文章发布，可以异步执行同步标签，或者在发布成功后默默同步。

   * **更稳妥的做法**：先同步标签，再发布文章。或者并行。

**注意**：用户之前的指令是“后端数据库最多支持10个保留”。
这意味着合并后的标签总数不能超过 10 个。
如果 `oldTags + newTags > 10`，怎么办？

* 保留最初的10个

* 保留用户前端的删除事件和用户的新增一起提交后端数据库优先执行删除，后执行增加

* 若用户在一次提交内既有删除又有新增，请前后端核对用户提交的标签差异，若新提交的和原有的标签相同则不管，若不同则以用户最新提交的为主，保留用户前

**完善后的计划**：

1. 在 `handleSubmit` 中：

   * 获取现有标签：`const res = await api.get('/users/tags');`

   * 合并标签：`const allTags = Array.from(new Set([...tags, ...(res.data || [])])).slice(0, 10);`

   * 同步标签：`await api.post('/users/tags', { tags: allTags });`

   * 继续执行文章发布逻辑。
